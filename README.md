# GP. Entry for Vest

A Tampermonkey userscript for [Vest](https://next.vestmarkets.com): a one-click order ticket with risk and reward dials you can also type into, your daily loss floor on the chart, a desk for all your accounts (switch, copy, and close or cut any of them), chart colour sets, and keyboard shortcuts you can switch on and set yourself.

> **Code GIGA at checkout.** GP. Entry puts referral code **GIGA** on every Vest account you buy, in place of any other code. It is on by default. To turn it off: the gear on the ticket (Settings) → **CODE GIGA AT CHECKOUT** → **off**.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Open **[gp-pulse.user.js](https://raw.githubusercontent.com/deciphe/gp-pulse/main/gp-pulse.user.js)** and press **Install**.
3. Reload Vest.

## Updates

Tampermonkey checks this repo and updates the script on its own. To pull an update right away: Tampermonkey → Dashboard → GP. Entry for Vest → **Check for updates**.

# GP. Dashboard for Vest

Your whole Vest profile in one screen: every account, every trade, what you spent and what you got paid, plus affiliate earnings. Press the GP. button on Vest.

Install: open **[gp-dashboard.user.js](https://raw.githubusercontent.com/deciphe/gp-pulse/main/gp-dashboard.user.js)** and press **Install**. It updates from this repo the same way.
